# formats.test.ts

포맷 레이어의 지정된 Vitest 검증을 모아요. node 환경에서 합성 fixture 전체의 JSON과 보존 바이너리 왕복을 확인해요. fixture 파일이나 생성기는 바꾸지 않아요.

- rpack의 0~255 바이트 왕복과 입력 불변성을 확인해요.
- risum의 인코딩된 에셋 블록과 JSON root의 알 수 없는 필드를 확인해요.
- module 없는 카드, JPEG 접두부, charx 항목 순서·보존 바이트와 로어북 사본 재생성을 확인해요.
- 큰 텍스트 ZIP 항목이 있는 charx를 내보내면 stored 방식보다 작아지고, 압축을 푼 내용과 보관된 바이너리는 그대로인지 확인해요.
- build의 입력 불변성, 읽기 전용 에셋 참조, 판별 우선순위, 오류 코드와 유효성 검사 경로를 확인해요.
- scalar 타입 불일치·필드 부재·잘못된 spec/type은 가져온 뒤 오류/경고로 알려지는지 확인해요. 편집 불가능한 객체·목록만 가져오기에서 거부하고, 실제 split/join/startsWith 실패는 내보내기 검증에서 막아요. ASCII o로 시작하는 일반 텍스트를 risum으로 오인하지 않는지도 확인해요.
- `fixtures/real/`에 지원하는 파일이 있으면 같은 왕복 검증을 실행하고, 없으면 명시적으로 건너뛰어요.
