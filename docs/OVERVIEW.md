# 개요

## 목표

RisuAI 파일(`.charx`, `.risum`, 로어북 `.json`)의 텍스트 내용을 편하게 편집하는 웹 앱.

## 원칙

- 설치 없이 웹에서 바로 사용 (GitHub Pages 정적 사이트. 완성 전까지는 배포하지 않아요)
- 모든 처리는 클라이언트에서만 (서버 전송 없음)
- 편집 대상은 텍스트뿐. 에셋은 보관만 하고 편집하거나 보여주지 않음
- PC 우선. 모바일은 깨지지 않을 정도만

## MVP 범위

2026-09-30 기준으로 아래 "포함" 항목은 모두 구현했어요. 진행 상황은 [STATUS.md](../STATUS.md)를 봐요.

**포함**
- 가져오기: `.charx`, `.risum`, 로어북 `.json`
- 레이아웃: 상단 바 + 탭 + 목록/편집기 2단
- 항목마다 폼 ⇄ JSON 전환, 모르는 필드 보존
- 항목 추가, 삭제 (로어북, 정규식, 트리거)
- 자동 저장, n분 스냅샷, 이벤트 스냅샷, 수동 스냅샷, 용량 기준 정리, 복원
- 새 파일 가져오기 시 경고 ([내보내고 계속] / [그냥 계속] / [취소])
- 내보내기: 원래 형식, 기본 유효성 검사

**MVP 이후**
- 검색·치환 (정규식 포함), CBS 하이라이팅, 로어북 정렬과 필터
- 원본 파일에 덮어쓰기 (File System Access API)
- 스냅샷 비교(diff) 화면
- 모바일 전용 레이아웃
- 탭 전체 JSON 보기
