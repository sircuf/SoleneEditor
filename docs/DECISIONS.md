# 결정 기록

바뀌면 지우지 말고 아래에 새 항목을 추가해요.

| 결정 | 이유 |
|---|---|
| APK가 아니라 GitHub Pages 웹 | 설치가 필요 없고, PC·iOS까지 지원하고, 업데이트가 즉시 반영돼요 |
| PWA 쓰지 않음 | 오프라인이 필요 없고, 업데이트 흐름이 단순해져요. 나중에 `vite-plugin-pwa`로 추가 가능 |
| Svelte 5 | 가볍고, RisuAI 본체가 Svelte + TS라 포팅이 쉬워요 |
| CodeMirror 6 | 모바일·한글 입력이 안정적이고 가벼워요 (Monaco는 모바일 미지원) |
| fflate | JSZip보다 빠르고 작아요 |
| 단일 문서 작업 공간 | MVP 단순화. 새 파일을 가져오면 기존 작업과 스냅샷을 삭제해요 |
| 스냅샷 보존은 용량 기준 | 한도를 넘으면 오래된 것부터 삭제. 원본·수동·내보낸 버전은 고정이라 제외 |
| 에셋은 보관만 | 편집 대상은 텍스트뿐. 스냅샷에는 에셋을 넣지 않아요 |
| 폼 ⇄ JSON 전환 | 데이터 원본은 하나. JSON 문법 오류 시 전환 차단. JSON 범위는 항목 단위 |
| PC 우선 | 모바일은 MVP에서 깨지지 않을 정도만 |
| ~~GPL-3.0~~ → AGPL-3.0 | RisuAI(GPL-3.0) 코드를 포팅하고, risum에 필요한 rpack이 RisuAI 밖에서는 AGPL-3.0이라서. 서버 없는 정적 사이트라 AGPL 추가 의무는 사실상 충족 |
| charx 내보내기 시 `character_book`을 module 로어북에서 다시 생성 | RisuAI 내보내기와 결과를 같게 하고, 다른 앱에서도 편집된 로어북이 보이게 하기 위해. 변환은 `exportCharacterCard`의 로어북 변환을 포팅 |
