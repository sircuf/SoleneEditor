# 서비스 구성

`createServices`는 계약의 네 서비스를 반환해요. 가져오기 prepare는 판별과 파싱만 수행해요. 성공한 prepare 객체를 비공개 WeakMap으로 확인하고 원본 결과 사본을 보관해요. commit은 자동 저장 예약을 취소하고 실행 중인 자동 저장·interval·직렬 작업을 기다린 뒤 Storage의 원자적 교체를 호출해요. 새 문서는 dirty가 꺼지고 원본 스냅샷이 고정돼요. 타이머는 commit 성공 여부와 관계없이 다시 시작해요.

내보내기는 검증, payload 조회, 분리된 문서 build, 다운로드 시작, 고정 export 스냅샷, dirty 해제 저장 순서예요. 경고는 허용하고 오류가 있으면 저장이나 다운로드를 하지 않아요. build 결과로 편집 문서를 바꾸지 않아요. 자동 저장 flush와 편집 차단은 호출자가 맡아요.

스냅샷 해시는 객체 키를 재귀적으로 UTF-16 코드 단위 순으로 정렬한 compact JSON의 UTF-8 바이트로 계산해요. 숫자처럼 생긴 객체 키도 순서를 지키도록 JSON 문자열을 직접 조립해요. JSON.stringify처럼 객체의 undefined 값은 키를 생략하고 배열의 undefined 값이나 빈 칸은 null로 인코딩해요. 배열 순서는 유지하고 Unicode는 정규화하지 않아요. SHA-256은 주입된 어댑터로 계산하며 size는 같은 바이트 수예요.

interval만 최신 스냅샷과 해시가 같으면 생략해요. original·manual·export는 고정하고 나머지는 비고정이에요. 모든 항목의 크기를 더한 뒤 시간·ID 순으로 오래된 비고정 항목부터 지워요. 고정 항목만 한도를 넘어도 유지해요. 추가·정리·삭제 뒤 구독자에게 분리된 목록을 전달해요.

복원 대상은 현재 저장소 목록에서 찾고 문서 종류를 확인해요. 대상 문서를 먼저 분리한 뒤 현재 문서의 before-restore 저장이 성공해야 workspace를 써요. 파일명·마지막 내보내기 시각·payload는 유지하고 draft를 지워요.

자동 저장은 1000ms debounce예요. 대체되거나 취소된 예약은 null로 끝나요. 일반 입력은 예약할 때 분리해서 호출자의 이후 변경을 막아요. 모든 JSON 하위 객체까지 동결된 레코드는 쓰기 시점까지 그대로 보관하고 실제 저장할 때 분리해요. 확인한 동결 객체를 WeakSet에 기억해서 다음 편집에서 공유된 하위 객체를 다시 확인하지 않아요. 최상위만 동결된 객체나 getter가 있는 객체는 이 최적화에서 제외해요.

실행 중인 쓰기는 직렬화하고 완료 시각을 결과로 반환해요. Storage와 반환값에도 각각 분리된 사본을 줘요. flush는 최신 예약을 바로 쓰고 앞선 작업까지 기다려요. cancel은 예약을 버리고 실행 중인 쓰기만 기다려요. dirty는 바꾸지 않아요.
