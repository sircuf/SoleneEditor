# 항목 주소와 보호 규칙

`items.ts`는 계약의 card.data·envelope.module·로어북·regex·trigger 위치를 찾고 교체해요. 문서 종류, 로어북 표현, 정수 index를 확인해요. 읽을 때 빠진 선택적 목록을 만들지 않고 addItem에서만 만들어서 원본의 필드 부재를 유지해요.

`copyEditPath`는 바뀔 항목까지의 부모 객체와 목록만 얕게 복사해요. 카드·module envelope·책 설정·그 밖의 항목은 바뀌지 않으면 동결된 기존 객체를 공유해요. 추가 시 필요한 빈 목록은 실제 추가 명령에서 만들어요.

JSON 값은 유한한 수·문자열·불리언·null·배열·일반 객체만 받아요. 바이너리·특수 객체·순환 참조·undefined는 거부해요. 각 항목의 필수 필드와 알려진 선택 필드의 타입을 확인하고 알 수 없는 필드는 그대로 받아요. 문서 전체 내보내기 검증은 FormatsApi가 맡아요.

전체 항목 교체는 알려진 필드 외의 기존 키를 잃지 않도록 확인해요. 알 수 없는 중첩 객체와 extensions류 컨테이너의 키도 보호해요. 카드의 책 설정과 module 목록 내부 항목의 알 수 없는 키를 확인하고 envelope는 교체하지 않아요. 계약에 정의된 card·module의 assets 참조는 의미·순서·존재 여부가 같아야 해요. payload 내부를 읽지 않아요.
