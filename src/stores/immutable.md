# 동결과 구조 공유

`freezeOwned`는 저장소가 소유한 일반 JSON 객체를 재귀적으로 동결해요. 자신이 처리한 객체만 WeakSet으로 기억하고 다시 만나면 탐색하지 않아요. 외부에서 최상위만 동결한 객체를 안전하다고 가정하지 않아요.

`detach`는 외부 JSON 객체를 새 배열·객체로 분리해요. 이 모듈이 이미 동결한 하위 객체는 호출자가 바꿀 수 없으므로 그대로 공유해요. `immutable`은 입력 분리와 동결을 함께 수행하고 `freezeOwned`는 이미 소유한 입력을 복사 없이 공개할 때 사용해요.

workspace는 처음 로드하거나 가져오기·내보내기·복원 결과를 받을 때 분리해요. 항목 편집은 부모 경로와 목록만 새로 만들고 바뀌지 않은 하위 객체를 공유해요. 이전 구독값도 계속 읽기 전용으로 유지돼요. draft·설정·UI 상태처럼 내부에서 계속 바꾸는 작은 객체는 분리한 값을 공개해요.
