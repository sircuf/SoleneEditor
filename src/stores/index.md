# 편집 상태와 명령

`createEditorStores`는 Storage·Services·FormatsApi·File 읽기 어댑터만 주입받아요. initialize가 workspace·설정·draft·스냅샷을 읽고 interval을 시작해요. 저장된 draft가 있으면 그 항목을 선택하고 JSON 모드로 열어요. 주소가 현재 문서와 맞지 않거나 항목이 사라졌다면 draft를 저장소에서도 지우고 기본 선택과 설정 모드로 초기화를 계속해요. 이 복구를 치명적 오류로 표시하지 않아요. dispose는 자동 저장과 draft 쓰기를 기다리고 interval과 구독을 정리해요.

상태 구독값은 깊게 동결해서 호출자가 바꿀 수 없어요. 외부 문서는 처음에 분리해서 소유하고, 편집할 때 바뀐 항목까지의 객체 경로와 배열만 복사해요. 이전 상태와 바뀌지 않은 하위 객체는 동결된 채로 공유해요. 입력의 새 객체는 분리하고 이미 소유한 동결 객체만 재사용해요. 폼과 JSON은 같은 workspace를 공유해요.

기본 선택은 첫 탭과 첫 항목이며 단일 객체나 빈 목록에서는 selectedIndex가 null이에요. 삭제는 기존 선택을 목록 안에 맞춰요. 누락된 선택적 목록은 추가할 때만 만들어요. 큰 로어북 편집 비용은 `benchmark.test.ts`에서 측정하며 시간 한도를 테스트 성공 조건으로 삼지 않아요.

updateJson의 문법이나 항목 구조가 잘못되면 draft만 바꿔요. 알 수 없는 키를 잃거나 에셋 참조를 바꾸는 입력은 오류로 거부해요. draft는 별도 대기열에서 저장·삭제해 빠른 입력의 순서를 유지해요. 유효한 입력은 문서를 바꾸고 draft를 지워요. draft가 있으면 다른 항목 편집·이동·모드 전환·내보내기를 막고, 명시적 폐기·가져오기 continue·복원으로 해제할 수 있어요.

기존 workspace가 있으면 dirty와 관계없이 File을 비공개로 보관하고 가져오기 확인을 열어요. 취소는 File과 대화상자만 버려요. continue는 prepare 성공 뒤 commit하며, export-then-continue는 현재 문서 내보내기가 성공해야 읽기와 prepare를 계속해요. 실패하면 기존 편집과 확인 대화상자를 유지해요.

가져오기·내보내기·복원은 busy를 먼저 설정하고 interval과 draft 쓰기를 기다려요. 내보내기·복원은 자동 저장도 flush해요. 늦게 끝난 자동 저장 결과는 완료 시각만 갱신하고 현재 문서를 덮어쓰지 않아요. 자동 저장 완료로 dirty를 끄지 않아요. 동기 명령 오류는 상태에 표시하고 throw하며, 비동기 명령 오류는 상태에 표시하고 reject해요.

설정 변경은 범위를 확인하고 저장한 뒤 interval을 다시 시작하고 보존 한도를 즉시 적용해요. draft가 있어도 테마·간격·용량 설정은 바꿀 수 있어요. 가져오기 확인은 confirmImport의 cancel로만 닫아요.
