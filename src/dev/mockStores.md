# mockStores.ts

createMockStores(options)는 문서와 명령 입력을 복제하고 기타 필드도 보존해요. 편집은 dirty를 켜고 유효하지 않은 JSON은 마지막 유효 문서를 바꾸지 않고 draft에 두어요.

options로 문서, 최초 dirty, 설정 일부, 내보내기 검사 결과를 지정해요. 원본·수동·내보내기·복원 전 스냅샷과 가져오기 확인 선택을 메모리에서 처리해요.

파일 내용을 파싱하지 않고 샘플로 가져오기를 대체해요. 크기는 JSON의 UTF-8 길이이고 hash는 고정 테스트 값이에요. canonical JSON·SHA-256·보존 한도 정리·주기 타이머는 서비스 레이어가 맡아요. 에셋 참조의 기본 비교만 하고 포맷별 검사를 대신하지 않아요.
