# FieldInput.svelte

필드 하나를 편집해요. 값은 로컬 버퍼에 두고 `pendingEdits`로 300ms 뒤에 `oncommit`을 호출해요.

- 포커스 중에는 stores 값이 바뀌어도 버퍼를 덮어쓰지 않아요. 포커스가 빠지면 저장된 값으로 다시 맞춰요(예: 숫자 "1.0" → 1).
- 한글 조합(compositionstart~end) 중에는 반영하지 않아요. 조합 중에 포커스가 빠지면 조합이 끝난 뒤 반영해요.
- `select`는 목록에 없는 기존 값도 "(알 수 없는 값)"으로 보여주고 바꾸지 않아요.
- `multiline-list`(다른 첫 메시지)는 항목마다 textarea를 둬서 줄바꿈이 항목을 나누지 않아요. 내용이 같으면 행을 다시 만들지 않아 포커스를 지켜요.
- 토글·선택·목록 추가/삭제는 바로 반영해요.
