# components

| 컴포넌트 | 역할 |
|---|---|
| TopBar | 파일명, 미저장 표시, 스냅샷·내보내기·가져오기 버튼 |
| Tabs | 포맷에 따라 카드 / 모듈 정보 / 로어북 / 정규식 / 트리거 |
| ItemList | 항목 목록, 선택, 추가, 삭제 |
| ItemEditor | 폼 ⇄ JSON 전환 |
| FormView | 스키마 기반 필드 폼. 폼에 없는 필드는 건드리지 않아요 |
| JsonView | CodeMirror 6, 문법 오류 표시 |
| Dialogs | 새 파일 경고, 스냅샷 목록, 복원 확인 |
