# components

`EditorApp.svelte`에 `stores: EditorStores`를 전달해요. UI는 `$contracts`와 schemas만 사용하고 실제 stores·services·formats·storage 구현을 가져오지 않아요. 초기화와 종료는 앱 wiring이 맡아요.

## 디자인

- 토큰과 공통 컨트롤 스타일은 [theme.css](theme.css)에 있어요. `.solene` 범위 안에서만 적용돼요.
- 밝은 테마는 "종이와 잉크"(미색 바탕), 어두운 테마는 "달빛 잉크"(짙은 남보라)예요. 강조색은 보라예요.
- 화면 구성: 상단 바 → 탭(항목 수) → 목록 | 문서형 편집기 → 상태 바.
- 짧은 필드는 2열, 긴 텍스트·목록은 전체 폭이에요. 긴 텍스트는 내용에 맞춰 늘어나고 글자 수를 보여줘요.
- 768px 미만에서는 목록을 편집기 위에 쌓고, 상단 바 버튼은 아이콘만 보여요.

## 입력 반영 규칙

- 입력은 필드마다 로컬 버퍼에 두고 300ms 뒤에 stores로 반영해요([pendingEdits.ts](pendingEdits.ts)).
- 한글 조합 중에는 반영하지 않고 조합이 끝난 뒤에 반영해요.
- 포커스가 있는 동안에는 stores의 값으로 입력 칸을 덮어쓰지 않아요. 커서가 튀지 않게 하기 위해서예요.
- 토글·선택 목록·인사말 추가/삭제는 바로 반영해요.
- 항목 이동, 탭 전환, 모드 전환, 내보내기·가져오기·스냅샷·설정 전에는 남은 입력을 먼저 반영해요.

## 파일

| 파일 | 역할 |
|---|---|
| EditorApp | 전체 레이아웃, 빈 화면, 토스트, 삭제 확인 |
| TopBar | 파일 칩(이름·종류·미저장), 스냅샷·설정·가져오기·내보내기 |
| Tabs | 포맷별 탭과 항목 수 |
| ItemList | 검색, 항목 목록(제목·키워드 미리보기·배지), 추가 |
| ItemEditor | 제목, 폼 ⇄ JSON 전환, 항목 삭제 |
| FormView | 스키마 기반 필드 배치. 폼에 없는 필드는 건드리지 않아요 |
| FieldInput | 필드 하나의 입력(텍스트·긴 글·숫자·토글·선택·목록·인사말 목록) |
| JsonView | CodeMirror 6, 문법 오류 위치 표시 |
| StatusBar | 자동 저장 시각, 마지막 내보내기, 스냅샷 수 |
| Dialogs | 새 파일 경고, 스냅샷 목록·용량, 복원 확인, 설정 |
| Modal | 네이티브 `<dialog>`, 포커스 복원, 하단 버튼 영역 |
| Icon | 선 아이콘 모음 (장식용, 항상 텍스트나 aria-label과 함께) |

`EditorApp.test.ts`는 개발용 mock으로 주요 흐름을 확인해요. 이 테스트에만 jsdom과 Svelte 브라우저 런타임을 적용해요.
